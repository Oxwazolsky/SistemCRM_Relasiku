# Adaptor Baileys untuk demo lokal (tidak resmi)

Ini bukan WhatsApp Cloud API dan tidak ditujukan untuk nomor produksi. Gunakan nomor WhatsApp **khusus demo**, bukan nomor bisnis pelanggan. Baileys memakai sesi WhatsApp Web: koneksi bisa putus, akun dapat dibatasi, dan sesi autentikasi di `auth/` setara akses ke akun. Jangan unggah atau bagikan `auth/` dan `.env`.

## Persiapan

1. Jalankan CRM pada `http://127.0.0.1:8000` (Laravel `php artisan serve --host=127.0.0.1 --port=8000`), database MySQL aktif, migrasi bot sudah diterapkan. Biarkan `WHATSAPP_CLOUD_ENABLED=false`.
2. Buat rahasia acak minimal 32 karakter. Isi `BAILEYS_DEMO_ENABLED=true` dan `BAILEYS_DEMO_SECRET=...` pada `.env` Laravel. Isi rahasia yang sama di `baileys-demo/.env` (salin `.env.example`). Jangan kirim rahasia lewat chat. Setelah mengubah `.env`, jalankan `php artisan config:clear` bila konfigurasi di-cache.
3. Isi `CRM_URL=http://127.0.0.1:8000`. Untuk uji terbatas, isi `DEMO_ALLOWLIST` dengan nomor HP penguji dalam format internasional tanpa `+`, dipisah koma (contoh `628123456789,628987654321`), dan biarkan `DEMO_OPEN_MODE=false`. Untuk demo lokal dengan siapa pun yang menghubungi nomor bot, set `DEMO_OPEN_MODE=true` secara eksplisit di `baileys-demo/.env` lalu restart `npm start`. Saat mode terbuka aktif, allowlist tidak membatasi pengirim. Bot hanya memproses chat pribadi teks (bukan grup), Laravel membatasi 20 pesan baru per pengirim per menit, dan inquiry baru dibuat setelah `SETUJU`. Jangan membagikan tautan ke calon pelanggan nyata atau mempublikasikan demo ini sebagai layanan produksi.
4. Dari `baileys-demo/`, jalankan `npm ci`, lalu `npm start`. Pindai QR di terminal memakai **nomor WA demo** melalui Perangkat tertaut. Simpan terminal tetap berjalan. Jangan jalankan proses ini pada server publik.
5. Kirim `MENU` dari nomor penguji yang ada di allowlist ke nomor demo. Lanjutkan `1` → nomor layanan → nama → email (opsional, balas `-` untuk melewati) → tanggal (`YYYY-MM-DD` atau `-`) → kebutuhan → `SETUJU`. Lihat inquiry di CRM sebagai Owner. Balas `CS` untuk melihat antrean serah-terima. CS dapat membalas secara manual dari WhatsApp di nomor demo; pesan yang dikirim dari nomor demo diabaikan oleh bot.

Setelah `CS` atau inquiry disetujui, bot berhenti membalas pesan berikutnya agar CS dapat membalas manual dari WhatsApp nomor demo. Pelanggan dapat mengetik `MENU` untuk mengaktifkan kembali bot. Jika pengiriman balasan WhatsApp gagal atau tidak pasti, terminal menampilkan `WhatsApp reply delivery uncertain`; periksa chat di ponsel bot secara manual. Tidak ada pengiriman ulang otomatis atau daftar kegagalan di CRM. Jika balasan gagal setelah CRM memproses pesan, jangan mengirim ulang pesan yang sama sembarangan: ID pesan sudah dideduplikasi di Laravel. Mulai lagi dengan pesan baru atau `MENU`; periksa koneksi Node dan Laravel. Untuk menghentikan mode terbuka, set `DEMO_OPEN_MODE=false` dan restart Node (allowlist tetap aktif); hentikan Node untuk mematikan semua balasan bot. Set `BAILEYS_DEMO_ENABLED=false` pada Laravel untuk menolak permintaan lokal baru.

Endpoint Laravel `/internal/baileys-demo/message` hanya menerima koneksi loopback dan header rahasia; jangan diteruskan melalui tunnel, proxy publik, atau port-forward. `auth/` dibuat saat pairing dan diabaikan git. Uji helper dengan `npm test`.
